## 🌦️ Nimbus — Weather Dashboard

A modern, responsive, and visually stunning Weather Dashboard built using HTML, CSS, and JavaScript.
Nimbus provides real-time weather updates, hourly forecasts, and a beautiful animated UI — all without requiring any API key.

---

## ✨ Features

* 🔍 Search weather by city name
* 🌡️ Toggle between Celsius (°C) and Fahrenheit (°F)
* 📊 Real-time weather data (temperature, humidity, wind, pressure, visibility)
* 🕐 Hourly forecast (scrollable timeline)
* 📅 3-day weather forecast
* 🌅 Sunrise & Sunset timing
* 🌈 Dynamic themes based on weather conditions
* 💾 Recent searches stored in localStorage
* ⚡ No API key required (uses wttr.in)
* 🎨 Glassmorphism UI + smooth animations
* 📱 Fully responsive design

## 🛠️ Tech Stack

* HTML5 – Structure
* CSS3 – Styling (Glassmorphism, Animations, Responsive Design)
* JavaScript (Vanilla JS) – Logic & API handling
* wttr.in API – Weather data (no key required)

---

## 💡 Key Concepts Used 

* DOM Manipulation
* Fetch API (Async/Await)
* Local Storage (Recent searches)
* Responsive Design (Media Queries)
* Dynamic Theming
* Animation & UI Effects
